# Predicting Used-Car Inventory Turnover with Naïve Bayes

Math for Data Science & AI term project (Project 1: Naïve Bayes Classification)
By Iftikhar Al Azzawi and Mustafa Al Hamowandi

Using data from Spangled Star Auto Sales, we predict whether a used car will sell
within 30 days (Fast Sale) or take longer (Slow Sale), using conditional probability,
Bayes' theorem, and Naïve Bayes.

## Contents
- `report/` - written report (Word)
- `presentation/` - presentation slides (PowerPoint)
- `app.py`, `nb_core.py`, `plots.py` - interactive Streamlit app that shows every calculation
- `Spangled_Star_Dataset.csv` - dataset used by the app

## Run the app
